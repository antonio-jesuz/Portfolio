# Portfólio — Antonio Jesuz (Nuxt 3 + Tailwind)

## Rodar localmente
    npm install
    npm run dev

## Publicar (grátis)
### Vercel ou Netlify (recomendado)
1. Suba esta pasta para um repositório no GitHub.
2. Importe o repositório na Vercel (vercel.com/new) ou Netlify.
3. Framework: Nuxt (detectado automaticamente). Build: `npm run build`.

### GitHub Pages (site estático)
    NUXT_APP_BASE_URL=/NOME-DO-REPO/ npm run generate
    # publique a pasta .output/public

## Editar conteúdo
Tudo (textos, links, projetos, stack) fica em `data/portfolio.ts`.
